概念知识

召回率

召回率（Recall）是指在所有实际为正类的样本中，被正确预测为正类的比例。公式为：

Recall=True Positives (TP)True Positives (TP)+False Negatives (FN) \text{Recall} = \frac{\text{True Positives (TP)}}{\text{True Positives (TP)} + \text{False Negatives (FN)}} Recall=True Positives (TP)+False Negatives (FN)True Positives (TP)​

召回率也可以叫做灵敏度（Sensitivity）或真阳性率（True Positive Rate, TPR）。

灵敏度出自医学领域，指的是在所有患病的人中，测试正确识别出患病的比例。高灵敏度意味着较少的假阴性（False Negatives, FN），即较少漏诊。

精确率

精确率（Precision）是指在所有被预测为正类的样本中，被正确预测为正类的比例。公式为：

Precision=True Positives (TP)True Positives (TP)+False Positives (FP) \text{Precision} = \frac{\text{True Positives (TP)}}{\text{True Positives (TP)} + \text{False Positives (FP)}} Precision=True Positives (TP)+False Positives (FP)True Positives (TP)​

特异性

特异性（Specificity）是指在所有实际为负类的样本中，被正确预测为负类的比例。公式为：

Specificity=True Negatives (TN)True Negatives (TN)+False Positives (FP) \text{Specificity} = \frac{\text{True Negatives (TN)}}{\text{True Negatives (TN)} + \text{False Positives (FP)}} Specificity=True Negatives (TN)+False Positives (FP)True Negatives (TN)​

出自医学领域，指的是在所有健康的人中，测试正确识别出健康的比例。高特异性意味着较少的假阳性（False Positives, FP），即较少误诊。

准确率 Accuracy

准确率表示所有样本中，被正确分类的比例：

Accuracy=TP+TNTP+TN+FP+FN \text{Accuracy} = \frac{TP+TN}{TP+TN+FP+FN} Accuracy=TP+TN+FP+FNTP+TN​

适合类别较均衡的问题。

如果类别极度不均衡，Accuracy 可能具有误导性。

例如 100 个样本中 99 个阴性，只预测全部为阴性，也有：

Accuracy=99% \text{Accuracy}=99\% Accuracy=99%

但模型实际上完全无法识别阳性。

F1 Score

F1 Score 是 Precision 和 Recall 的调和平均：

F1=2Precision⋅RecallPrecision+Recall F_1 = 2\frac{\text{Precision}\cdot\text{Recall}} {\text{Precision}+\text{Recall}} F1​=2Precision+RecallPrecision⋅Recall​

也可以写为：

F1=2TP2TP+FP+FN F_1 = \frac{2TP}{2TP+FP+FN} F1​=2TP+FP+FN2TP​

适合同时关注漏检和误检的问题。

数据泄漏 Data Leakage

数据泄漏指训练过程中使用了本不应该获得的测试信息。

例如：

先在全部数据上计算均值和标准差：

μ=1N∑xi \mu=\frac1N\sum x_i μ=N1​∑xi​

再划分训练集和测试集。

这样测试集信息已经进入数据预处理。

简单来说就是测试集的特征已经被训练集使用过了，导致模型在测试集上表现异常好，但实际上泛化能力很差。

正确做法：

只用训练集计算预处理参数，然后应用到验证集和测试集。

Adam 同时维护梯度的一阶矩和二阶矩。

mt=β1mt−1+(1−β1)gt m_t = \beta_1m_{t-1} + (1-\beta_1)g_t mt​=β1​mt−1​+(1−β1​)gt​

二阶矩：

θt=θt−1−ηm^tv^t+ϵ \theta_t = \theta_{t-1} - \eta \frac{\hat m_t} {\sqrt{\hat v_t}+\epsilon} θt​=θt−1​−ηv^t​​+ϵm^t​​

直观理解：

Adam 会根据历史梯度自动调整不同参数的更新步长。

mtm_tmt​和vtv_tvt​写成那样，是因为：

用指数移动平均来估计梯度的近期一阶矩和二阶矩。

泛化与正则化

过拟合 Overfitting

模型：

训练集表现很好
验证集/测试集表现明显较差

说明模型记住了训练数据中的细节或噪声，而没有学习可泛化规律。

通常说明：

模型过于简单
训练不足
特征不足

L1 正则化

在损失函数中加入参数绝对值惩罚：

L′=L+λ∑i∣wi∣ L' = L + \lambda \sum_i |w_i| L′=L+λi∑​∣wi​∣

使参数更容易变得为0，从而实现特征选择。

L2 正则化

在损失函数中加入参数平方惩罚：

L′=L+λ∑iwi2 L' = L + \lambda \sum_i w_i^2 L′=L+λi∑​wi2​

使参数不容易变得过大。

在神经网络优化中常对应：

Weight Decay

两种正则化的区别：

L1 L2
别名 Lasso Ridge
正则项 ∑∥wj∥\sum \|w_j\|∑∥wj​∥ ∑wj2\sum w_j^2∑wj2​
权重效果 很多变成 0 整体变小，很少为 0

可解释性 强 弱一些

贝叶斯视角 拉普拉斯先验 高斯先验

怎么选？

  • 如果特征很多，而且你猜只有少数有用：
    用 L1。

  • 如果特征都有贡献，或者特征之间相关性很强：
    用 L2。

  • 如果既想稀疏，又想处理共线性：
    用 Elastic Net，也就是 L1 + L2。

Loss+λ1∑∣wj∣+λ2∑wj2 \text{Loss} + \lambda_1 \sum |w_j| + \lambda_2 \sum w_j^2 Loss+λ1​∑∣wj​∣+λ2​∑wj2​
  • 深度学习里默认更常用：
    L2 / weight decay，因为它稳定、好优化。

一句话总结
L1 像“删特征”：把不重要的权重直接砍成 0，适合稀疏和特征选择。
L2 像“压权重”：把所有参数都变小一点，防止过拟合，适合稳定模型。
两者都常用，但通常都要先标准化。

交叉熵与均方误差

回归问题常用的损失函数是均方误差（Mean Squared Error, MSE），而分类问题常用的损失函数是交叉熵（Cross Entropy）。两者的区别在于：

  • 均方误差适用于回归问题，即预测连续值的任务。
  • 交叉熵适用于分类问题，即预测离散类别的任务。

交叉熵：

  • 用预测分布 q 去编码真实分布 p 的数据，平均花多少信息量。公式为：H(p,q)=−∑xp(x)log⁡q(x) H(p, q) = -\sum_{x} p(x) \log q(x) H(p,q)=−x∑​p(x)logq(x) 其中，p p p 是真实分布，q q q 是预测分布。
    - 本质是信息量的期望

KL散度：

  • q 代替 p 后额外浪费的信息量。KL ≥ 0，等于 0 时 p=q。公式为：DKL(p∣∣q)=∑xp(x)log⁡p(x)q(x) D_{KL}(p || q) = \sum_{x} p(x) \log \frac{p(x)}{q(x)} DKL​(p∣∣q)=x∑​p(x)logq(x)p(x)​ KL散度是非对称的，表示从分布 q q q 到分布 p p p 的信息损失。

交叉熵与KL散度的关系：

  • KL散度可以表示为交叉熵与熵的差：DKL(p∣∣q)=H(p,q)−H(p) D_{KL}(p || q) = H(p, q) - H(p) DKL​(p∣∣q)=H(p,q)−H(p)

关于交叉熵的p(x)

  • 交叉熵中的 p(x) p(x) p(x) 是指真实分布的概率值，通常在分类问题中，p(x) p(x) p(x) 是一个one-hot向量（独热编码），表示样本属于某个类别的概率为1，其余类别的概率为0。

为什么交叉熵比均方误差更适合分类问题？

当模型非常自信的预测错误，例如经过sigmoid，真实答案是1，而预测0.001，表示模型有99.9%的把握认为它不是 1
为什么MSE出现这个问题：
logits为z，经过sigmoid后为y^，真实标签为y
y^ = sigmoid(z) = 1 / (1 + exp(-z))
经过反向传播：
由于：

y^=σ(z) \hat y=\sigma(z) y^​=σ(z)

所以链式法则：

∂L∂z=∂L∂y^⋅∂y^∂z \frac{\partial L}{\partial z} = \frac{\partial L}{\partial \hat y} \cdot \frac{\partial \hat y}{\partial z} ∂z∂L​=∂y^​∂L​⋅∂z∂y^​​

MSE 第一部分：

∂L∂y^=2(y^−y) \frac{\partial L}{\partial \hat y} = 2(\hat y-y) ∂y^​∂L​=2(y^​−y)

而 sigmoid 的梯度：

∂y^∂z=y^(1−y^) \frac{\partial \hat y}{\partial z} = \hat y(1-\hat y) ∂z∂y^​​=y^​(1−y^​)

则

∂L∂z=2(y^−y)⋅y^(1−y^) \frac{\partial L}{\partial z} = 2(\hat y-y) \cdot \hat y(1-\hat y) ∂z∂L​=2(y^​−y)⋅y^​(1−y^​)

当y^接近0或1时，sigmoid的梯度会变得非常小，导致整个梯度也变得非常小，从而使得模型训练缓慢，甚至可能陷入梯度消失的问题

交叉熵的梯度会把sigmoid的梯度消掉，直接得到：

∂L∂z=y^−y \frac{\partial L}{\partial z} = \hat y - y ∂z∂L​=y^​−y

神经网络基础

为什么需要激活函数

本质上，神经网络是由多个线性变换（加权求和）和非线性激活函数组成的
如果没有非线性变换，所有的线性变换可以被合并为一个线性变换，无法表示复杂的非线性关系
激活函数会产生高阶特征，使得神经网络可以拟合复杂的非线性函数

蓝色大鲸鱼改版
其实不能说产生了高阶特征，他没有直接显式得到像x2x^2x2这样的高阶特征，而是通过非线性激活函数的组合，使得网络可以间接学习到复杂的非线性关系和高阶交互特征。
本质上，神经网络由多个线性/仿射变换和非线性激活函数交替组成。
如果没有非线性激活，所有线性/仿射变换可以合并为一个仿射变换，深度失去意义，无法表示复杂非线性关系。
激活函数引入非线性，使多层复合不再是单一线性映射，从而极大提升表达能力，使网络能够逼近复杂非线性函数；通过多层非线性组合，可以间接学习高阶交互和抽象特征。

  • sigmoid函数用于二分类问题，将输入映射到0到1之间的概率值
  • softmax函数用于多分类问题，将输入映射到0到1之间的概率值，并且所有类别的概率和为1

反向传播时，根据链式法则：

∂L∂x=∂L∂hn∏i=1n∂hi∂hi−1 \frac{\partial L}{\partial x} = \frac{\partial L}{\partial h_n} \prod_{i=1}^{n} \frac{\partial h_i}{\partial h_{i-1}} ∂x∂L​=∂hn​∂L​i=1∏n​∂hi−1​∂hi​​

如果很多梯度都小于 1，连续相乘后：

∏i∂hi∂hi−1→0 \prod_i \frac{\partial h_i}{\partial h_{i-1}} \rightarrow0 i∏​∂hi−1​∂hi​​→0

导致前层参数几乎无法更新。

梯度爆炸

如果连续相乘的梯度很多大于 1：

∏i∂hi∂hi−1→∞ \prod_i \frac{\partial h_i}{\partial h_{i-1}} \rightarrow\infty i∏​∂hi−1​∂hi​​→∞

可能导致训练不稳定。

常见方法：

  1. Gradient Clipping
    直接限制梯度大小，裁剪
    梯度太大就按比例缩小，防止一步更新炸掉。
    常用：clip_grad_norm_(model.parameters(), max_norm=1.0)。

  2. 合理初始化
    深度网络是一层层线性变换加非线性激活。
    如果权重初始化不合适，每一层的输出方差可能比输入方差大一点，经过很多层就会指数放大，导致前向激活爆炸，反向梯度也爆炸。
    反过来，如果每层都缩小一点，就会指数衰减，导致梯度消失。
    所以训练刚开始时要做合理的权重初始化，让每一层的前向方差和反向梯度方差大致保持稳定，避免梯度爆炸或消失。

让前向和反向传播时数值别被放大或缩小。
ReLU 用 He 初始化，Tanh/Sigmoid 用 Xavier 初始化。
初始化太大会炸，太小会消失。

  1. Normalization
    稳定每层输入分布。
    CNN 常用 BatchNorm，Transformer/RNN 常用 LayerNorm。
    让训练更稳，梯度不容易爆炸或消失。

BatchNorm 跨样本，按特征归一化
LayerNorm 跨特征，对同一样本归一化

BatchNorm 适合 CNN
CNN 里每个通道代表一种特征，比如边缘、纹理。
同一个通道在不同图片、不同位置都应该有相似分布。
所以跨样本、跨空间位置统计是合理的。
而且 CNN 通常 batch 比较大，统计量稳定。
BatchNorm 还能加速训练、允许更大学习率。
但缺点：
batch 太小时，均值和方差估计不准。
RNN、变长序列里，不同时间步长度不同，不好跨样本统计。
训练和推理行为不一致，推理时要用滑动平均。

LayerNorm 适合 Transformer / RNN
Transformer 和 RNN 处理序列，每个样本长度可能不同。
如果跨样本统计，变长序列会很难对齐。
LayerNorm 对每个样本独立归一化：
不依赖 batch size
训练和推理行为一致
对变长序列友好
Transformer 里每个 token 的表示维度是 D，LayerNorm 在D上归一化，非常自然。

  1. Residual Connection
    给梯度开一条捷径。
    写成 x = x + F(x)，梯度可以直接回传。
    深层网络更稳，主要缓解梯度消失，也能间接缓解爆炸。

    这个就是 ResNet 的核心思想。

Kernel Trick 核技巧

有些数据在线性空间中无法很好分开。

理论上可以将输入映射到高维空间：

x→ϕ(x) x\rightarrow\phi(x) x→ϕ(x)

但直接计算高维 (\phi(x)) 可能很昂贵。

核函数直接计算：

K(xi,xj)=ϕ(xi)Tϕ(xj) K(x_i,x_j) = \phi(x_i)^T\phi(x_j) K(xi​,xj​)=ϕ(xi​)Tϕ(xj​)

而不显式计算 (\phi(x))。

常见 RBF 核：

K(xi,xj)=exp⁡(−γ∥xi−xj∥2) K(x_i,x_j) = \exp \left( -\gamma\|x_i-x_j\|^2 \right) K(xi​,xj​)=exp(−γ∥xi​−xj​∥2)

直观理解：

核技巧让线性算法能够描述非线性关系。

核函数 公式 特点
线性核 xTyx^TyxTy 不映射，就是原始空间
多项式核 (xTy+c)d(x^Ty+c)^d(xTy+c)d 多项式特征
RBF 核 exp⁡(−γ∥x−y∥2)\exp(-\gamma\|x-y\|^2)exp(−γ∥x−y∥2) 无穷维映射，最常用
Sigmoid 核 tanh⁡(αxTy+c)\tanh(\alpha x^Ty+c)tanh(αxTy+c) 类似神经网络

核技巧就是：
不显式地把数据映射到高维，而是用一个核函数 K(x,y)K(x,y)K(x,y) 直接计算高维空间的内积。
这样就能用低维计算，得到高维非线性效果。
SVM、SVR 靠它处理非线性问题，同时保持计算可行和稀疏解。

贝叶斯线性回归

普通线性回归把参数 w\mathbf ww 看作一个确定值。

贝叶斯方法把参数看成概率分布。

例如给权重设置高斯先验：

p(w)=N(0,λ−1I) p(\mathbf w) = \mathcal N(\mathbf 0,\lambda^{-1}I) p(w)=N(0,λ−1I)

观测模型：

y=Xw+ϵ y=X\mathbf w+\epsilon y=Xw+ϵ

其中：

ϵ∼N(0,α−1I) \epsilon\sim \mathcal N(0,\alpha^{-1}I) ϵ∼N(0,α−1I)

根据贝叶斯公式：

p(w∣D)∝p(D∣w)p(w) p(\mathbf w|D) \propto p(D|\mathbf w)p(\mathbf w) p(w∣D)∝p(D∣w)p(w)

得到权重的后验分布。

因此预测结果不仅可以给出：

预测均值

还可以给出：

预测不确定性。

Bayesian Ridge 可以理解为：

Ridge Regression 的贝叶斯版本。

Ridge 使用 L2 正则化：

L=∥y−Xw∥2+λ∥w∥2 L = \|y-Xw\|^2 + \lambda\|w\|^2 L=∥y−Xw∥2+λ∥w∥2

从贝叶斯角度看：

w∼N(0,λ−1I) w\sim\mathcal N(0,\lambda^{-1}I) w∼N(0,λ−1I)

即对权重施加高斯先验。

这和你的项目非常重要：

探索与利用 Exploration vs Exploitation

在实验推荐问题里存在一个基本矛盾：

Exploitation 利用

优先测试：

当前模型认为最好的实验条件。

Exploration 探索

优先测试：

当前模型最不确定、但可能带来新信息的实验条件。

只 Exploitation：

容易陷入当前已知最优附近。

只 Exploration：

会浪费大量实验资源。

因此需要平衡：

Exploration↔Exploitation \text{Exploration} \quad\leftrightarrow\quad \text{Exploitation} Exploration↔Exploitation

UCB

Upper Confidence Bound，上置信界。

假设模型对一个候选条件 xxx 给出：

预测均值：

μ(x) \mu(x) μ(x)

预测标准差：

σ(x) \sigma(x) σ(x)

UCB：

UCB(x)=μ(x)+κσ(x) UCB(x) = \mu(x)+\kappa\sigma(x) UCB(x)=μ(x)+κσ(x)

其中：

(\mu(x))：模型认为这个实验有多好
(\sigma(x))：模型有多不确定
(\kappa)：探索程度

选择：

xnext=arg⁡max⁡x[μ(x)+κσ(x)] x_{next} = \arg\max_x \left[ \mu(x)+\kappa\sigma(x) \right] xnext​=argxmax​[μ(x)+κσ(x)]

UCB 的直观理解

如果一个条件：

μ=0.8,σ=0.05 \mu=0.8,\quad\sigma=0.05 μ=0.8,σ=0.05

另一个：

μ=0.7,σ=0.3 \mu=0.7,\quad\sigma=0.3 μ=0.7,σ=0.3

第二个虽然预测均值较低，但不确定性很高，仍可能获得较大的 UCB。

所以 UCB 会同时考虑：

看起来好的 + 还没有探索清楚的。

约束 UCB

实验中并不是所有数学上推荐的条件都可以执行。

因此可以限定可行域：

x∈F x\in\mathcal F x∈F

然后：

xnext=arg⁡max⁡x∈FUCB(x) x_{next} = \arg\max_{x\in\mathcal F} UCB(x) xnext​=argx∈Fmax​UCB(x)

其中 F\mathcal FF 可以包含：

  • 浓度范围
  • 安全约束
  • 实验可操作性
  • 已知无效组合
  • 配方组成限制

所以你的项目中的“约束 UCB”可以解释为：

在利用预测均值和不确定性选择候选的同时，通过实验规则限制候选空间，避免模型推荐无法执行或明显不合理的组合。

模型本身过于简单。

高 Bias：

容易欠拟合。

模型对训练数据变化过于敏感。

高 Variance：

容易过拟合。

小样本任务特别需要控制 Variance。

卷积主要利用：

  1. 局部连接
    局部连接主要指卷积核的有限感受野。卷积核只关注输入数据的局部区域，而不是整个输入。这种局部连接的方式使得卷积神经网络能够有效地捕捉局部特征，如边缘、纹理等，从而提高模型的表达能力和泛化能力。
  2. 权重共享
    权重共享和RNN的不一样，CNN的权重共享是在空间上的共享，卷积核在整个输入图像上滑动时，使用相同的权重参数。这种共享机制大大减少了模型的参数数量，降低了计算复杂度，同时也增强了模型对平移不变性的鲁棒性。通过权重共享，卷积神经网络能够在不同位置上识别相同的特征，从而提高模型的泛化能力。

F(x)=H(x)−x F(x)=H(x)-x F(x)=H(x)−x

作用：

让深层网络更容易优化，同时改善梯度传播。

Attention

Attention 的核心思想：

根据 Query 与 Key 的相关程度，对 Value 加权求和。

公式：

Attention(Q,K,V)=softmax(QKTdk)V \text{Attention}(Q,K,V) = \text{softmax} \left( \frac{QK^T}{\sqrt{d_k}} \right)V Attention(Q,K,V)=softmax(dk​​QKT​)V

其中：

QQQ：Query KKK：Key VVV：Value dkd_kdk​：Key 的维度

为什么除以 dk\sqrt{d_k}dk​​

如果 dkd_kdk​ 很大，点积：

QKT QK^T QKT

的绝对值会变大，使 softmax 过于尖锐（陷入两端的饱和区，梯度消失），梯度变小。

因此除以：

dk \sqrt{d_k} dk​​

稳定数值范围。

Self-Attention

Self-Attention 中：

Q=XWQ Q=XW_Q Q=XWQ​ K=XWK K=XW_K K=XWK​ V=XWV V=XW_V V=XWV​

三者都来自同一个输入序列 XXX。

同一个输入序列，分别投影成了 Q、K、V 三种角色。
这就是 Self-Attention 里的“self”：自己和自己交互。
其中的WQW_QWQ​、WKW_KWK​、WVW_VWV​是可学习的参数矩阵。

作用：

序列中的每个 token 都能根据其他 token 的信息更新自己的表示

也就是可以计算attention output，得到每个token的新的表示
例如对于第i个token，它的原始输入表示是xix_ixi​,这是这个词的静态向量，来自于embedding和位置编码，经过self-attention后，它的表示会被更新为xi′x_i'xi′​，这个新的表示xi′x_i'xi′​是根据所有token的表示加权得到的，其中权重来自于attention机制。

这个新的表示xi′x_i'xi′​一般可以称为第i个token的attention output，或者说是context vector，或者是context representation

Multi-Head Attention

不是只计算一次 Attention，而是并行计算多个 Attention Head（不同的权重矩阵W）：

headi=Attention(QWiQ,KWiK,VWiV) head_i = Attention(QW_i^Q,KW_i^K,VW_i^V) headi​=Attention(QWiQ​,KWiK​,VWiV​)

然后：

MultiHead(Q,K,V)=Concat(head1,…,headh)WO MultiHead(Q,K,V) = Concat(head_1,\ldots,head_h)W^O MultiHead(Q,K,V)=Concat(head1​,…,headh​)WO

作用：

不同 Head 可以学习不同类型的关系。

多头的W是如何产生的？
一开始是随机初始化的，然后通过反向传播自己学出来的。
训练前，每个头的W都随机不同。
训练后，不同头会逐渐分化，各自关注不同模式。
有些头可能学到相似功能，有些头可能很专门。
这是数据驱动涌现的，不是人硬编码的。

Positional Encoding

Transformer 本身没有循环结构，因此 Attention 不知道 token 的顺序。

需要加入位置信息。

经典位置编码：

PE(pos,2i)=sin⁡(pos100002i/d) PE(pos,2i) = \sin \left( \frac{pos} {10000^{2i/d}} \right) PE(pos,2i)=sin(100002i/dpos​) PE(pos,2i+1)=cos⁡(pos100002i/d) PE(pos,2i+1) = \cos \left( \frac{pos} {10000^{2i/d}} \right) PE(pos,2i+1)=cos(100002i/dpos​)

正弦-余弦位置编码
偶数维正弦，奇数维余弦，交替排列。

编码如何用到训练过程中的

经典transformer的position encoding是固定的，不会随着训练更新。它是一个预定义的函数，直接计算出每个位置的编码向量。

为什么直接将token embedding和位置编码相加
因为相加可以让模型在同一个空间里同时表示：
词义信息（来自 token embedding）
位置信息（来自位置编码）
如果拼接，维度会翻倍，参数量变大。
相加是原始 Transformer 的选择，简单有效。

现代transformer会用RoPE（旋转位置编码）或者learnable position embedding，都是为了让模型更好地捕捉位置信息。

Layer Normalization

LayerNorm 对单个样本内部的特征进行标准化：

μ=1d∑i=1dxi \mu = \frac1d \sum_{i=1}^{d}x_i μ=d1​i=1∑d​xi​ σ2=1d∑i=1d(xi−μ)2 \sigma^2 = \frac1d \sum_{i=1}^{d}(x_i-\mu)^2 σ2=d1​i=1∑d​(xi​−μ)2 x^i=xi−μσ2+ϵ \hat x_i = \frac{x_i-\mu} {\sqrt{\sigma^2+\epsilon}} x^i​=σ2+ϵ​xi​−μ​

Transformer 中通常使用 LayerNorm，而不是 BatchNorm。
具体的前面CNN已经提到了

VLM / VLA

VLM

Vision-Language Model：

同时处理视觉和语言信息的模型。

典型结构：

Image→Vision Encoder→Visual Features→Projector→LLM Image \rightarrow Vision\ Encoder \rightarrow Visual\ Features \rightarrow Projector \rightarrow LLM Image→Vision Encoder→Visual Features→Projector→LLM

语言输入则进入 LLM，与视觉信息共同推理。

VLA

Vision-Language-Action Model：

在 VLM 基础上进一步把视觉和语言信息映射为机器人动作。

可以抽象为：

at=π(ot,l,st) a_t = \pi(o_t,l,s_t) at​=π(ot​,l,st​)

其中：

oto_tot​：视觉观测 lll：语言指令 sts_tst​：机器人状态 ata_tat​：机器人动作 π\piπ：策略

Policy

Policy 即策略：

π(a∣s) \pi(a|s) π(a∣s)

表示：

  • 给定状态 sss，采取动作 aaa 的规则或概率。

策略学习不等于强化学习。

模仿学习和强化学习都可以用于学习策略。

如何理解策略网络
策略网络就是神经网络
区别在于输入输出，目标、训练方式

普通神经网络 策略网络
输入 图片、文本、表格 状态 sss：图像、关节角、语言指令等
输出 类别、数值 动作 aaa：关节扭矩、速度、动作 token
目标 分类、回归 控制机器人 / 做决策
训练方式 监督学习 行为克隆、强化学习、或两者结合
本质 函数逼近器 函数逼近器

本质都是函数逼近器。

策略网络并没有发明一种全新的网络结构。
它只是把神经网络用在了“决策”这个任务上。

策略网络可以用任何架构

  • 简单机器人：MLP 就够了。
  • 看图像的机器人：CNN + MLP。
  • 处理序列：RNN / LSTM。
  • VLA：Transformer，输入图像 + 语言，输出动作。

所以 VLA 里的策略网络，往往就是：

一个 Transformer/VLM，接一个动作头。

它和 GPT 的区别只是：

  • GPT 输出下一个 token。
  • VLA 策略网络输出下一个动作 token 或连续动作。

VLA 策略网络通常是：

它内部用的全是我们前面讲过的组件：

  • CNN / ViT
  • Transformer
  • Self-Attention
  • LayerNorm
  • 残差连接

Behavior Cloning

行为克隆是一种最直接的模仿学习。

给定专家示范：

D={(si,ai)}i=1N D= \{(s_i,a_i)\}_{i=1}^{N} D={(si​,ai​)}i=1N​

训练模型预测专家动作：

πθ(si)≈ai \pi_\theta(s_i) \approx a_i πθ​(si​)≈ai​

例如使用 MSE：

L=1N∑i∥πθ(si)−ai∥2 L = \frac1N \sum_i \| \pi_\theta(s_i)-a_i \|^2 L=N1​i∑​∥πθ​(si​)−ai​∥2

本质：

把机器人控制当作监督学习。

在 VLA 里，Behavior Cloning 怎么用？

这就是 Behavior Cloning。

很多 VLA 模型，比如 RT-1、RT-2、OpenVLA，第一阶段训练都大量依赖 Behavior Cloning。

连续动作

比如机械臂关节角度、速度、力矩。

用 MSE：

L=1N∑i∥πθ(si)−ai∥2L = \frac{1}{N}\sum_i \left\|\pi_\theta(s_i) - a_i\right\|^2L=N1​∑i​∥πθ​(si​)−ai​∥2

离散动作

把动作离散成 token，像语言模型一样预测。

用交叉熵：

L=−1N∑ilog⁡pθ(ai∣si)L = -\frac{1}{N}\sum_i \log p_\theta(a_i|s_i)L=−N1​∑i​logpθ​(ai​∣si​)

现代 VLA 很多走离散 token 路线，因为可以直接复用语言模型架构。

如何离散化动作

把每个关节角度切成很多小格子，比如：

每个 bin 给一个编号，比如 0 到 255。
这样动作就变成了：

a=[bin12, bin87, bin203, … ]a = [\text{bin}_{12},\ \text{bin}_{87},\ \text{bin}_{203},\ \dots]a=[bin12​, bin87​, bin203​, …]

每个维度是一个离散类别。
模型不再输出实数，而是输出每个 bin 的概率分布：

pθ(a∣s)p_\theta(a|s)pθ​(a∣s)

这时候真实动作是某个具体 bin，预测是一个概率分布，自然用交叉熵：

L=−1N∑ilog⁡pθ(ai∣si)L = -\frac{1}{N}\sum_i \log p_\theta(a_i|s_i)L=−N1​∑i​logpθ​(ai​∣si​)

交叉熵衡量的是预测分布和真实类别之间的差异，适合分类。

为什么现代 VLA 喜欢离散 token？

因为可以直接复用语言模型架构。

语言模型做的是：

p(next token∣context)p(\text{next token}|\text{context})p(next token∣context)

用交叉熵训练。

如果你把动作也变成 token：

动作=[token12, token87, token203]\text{动作} = [\text{token}_{12},\ \text{token}_{87},\ \text{token}_{203}]动作=[token12​, token87​, token203​]

那么 VLA 就可以统一成：

p(next token∣图像,语言,历史动作)p(\text{next token}|\text{图像},\text{语言},\text{历史动作})p(next token∣图像,语言,历史动作)

和语言模型一模一样。

好处：

  • 直接复用 Transformer、softmax、交叉熵。
  • 图像、语言、动作全在一个 token 空间里。
  • 可以借用语言模型的预训练权重。
  • 训练稳定，工程实现简单。
  • 能建模多模态动作分布：同一个状态，多个合理动作都有概率。

Embedding

Embedding 是把离散信息映射到连续向量空间：

x→e∈Rd x \rightarrow \mathbf e\in\mathbb R^d x→e∈Rd

语义相近的信息，其 Embedding 通常也比较接近。

Cosine Similarity

两个向量的余弦相似度：

cos⁡(θ)=a⋅b∥a∥∥b∥ \cos(\theta) = \frac{ \mathbf a\cdot\mathbf b }{ \|\mathbf a\| \|\mathbf b\| } cos(θ)=∥a∥∥b∥a⋅b​

值越接近 1，通常表示方向越相似。

RAG 中常用于语义检索。

RAG

Retrieval-Augmented Generation：

Question→Retrieval→Context→LLM→Answer Question \rightarrow Retrieval \rightarrow Context \rightarrow LLM \rightarrow Answer Question→Retrieval→Context→LLM→Answer

核心思想：

不要求模型把全部专业知识记在参数里，而是在生成答案前先从外部知识库检索相关信息。

实验室场景可以检索：

SOP
仪器手册
安全规则
历史实验记录

Agent

Agent 可以简单理解为：

Agent=LLM+Tools+State+Workflow Agent = LLM + Tools + State + Workflow Agent=LLM+Tools+State+Workflow

相比普通聊天模型，Agent 可以：

理解目标

调用工具

Tool Calling

模型不是直接执行设备，而是输出结构化工具调用，例如：

pipette(volume=100 μL,source=A,target=B) \text{pipette} ( volume=100\ \mu L, source=A, target=B ) pipette(volume=100 μL,source=A,target=B)

实际执行由确定性程序完成。

实验室自动化中：

LLM 可以决定“调用哪个工具”，但安全约束和底层执行不应完全交给 LLM。

最后再补一个非常适合你面试的概念

Task Success 与 Experimental Success

机器人任务成功：

Task Success=I(action completed) Task\ Success = \mathbb I(\text{action completed}) Task Success=I(action completed)

例如：

机器人成功执行了“移液 100 (\mu L)”动作。

但实验成功还可能要求：

Experimental Success=f(volume accuracy,contamination,sample state,protocol constraints,measurement validity) Experimental\ Success = f( \text{volume accuracy}, \text{contamination}, \text{sample state}, \text{protocol constraints}, \text{measurement validity} ) Experimental Success=f(volume accuracy,contamination,sample state,protocol constraints,measurement validity)

因此：

Task Success⇏Experimental Success Task\ Success \not\Rightarrow Experimental\ Success Task Success⇒Experimental Success

即：

机器人动作完成，并不意味着实验真正成功。

这其实正是你这次面试最值得讲清楚的核心思想。
