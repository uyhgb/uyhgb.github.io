交叉熵与均方误差

回归问题常用的损失函数是均方误差（Mean Squared Error, MSE），而分类问题常用的损失函数是交叉熵（Cross Entropy）。两者的区别在于：

  • 均方误差适用于回归问题，即预测连续值的任务。
  • 交叉熵适用于分类问题，即预测离散类别的任务。

交叉熵：

  • 用预测分布 q 去编码真实分布 p 的数据，平均花多少信息量。公式为：
    [
    H(p, q) = -\sum_{x} p(x) \log q(x)
    ]
    其中，(p) 是真实分布，(q) 是预测分布。
    - 本质是信息量的期望

KL散度：

  • q 代替 p 后额外浪费的信息量。KL ≥ 0，等于 0 时 p=q。公式为：
    [
    D_{KL}(p || q) = \sum_{x} p(x) \log \frac{p(x)}{q(x)}
    ]
    KL散度是非对称的，表示从分布 (q) 到分布 (p) 的信息损失。

交叉熵与KL散度的关系：

  • KL散度可以表示为交叉熵与熵的差：
    [
    D_{KL}(p || q) = H(p, q) - H(p)
    ]

关于交叉熵的p(x)

  • 交叉熵中的 (p(x)) 是指真实分布的概率值，通常在分类问题中，(p(x)) 是一个one-hot向量（独热编码），表示样本属于某个类别的概率为1，其余类别的概率为0。

sigmoid与softmax

  • sigmoid函数用于二分类问题，将输入映射到0到1之间的概率值
  • softmax函数用于多分类问题，将输入映射到0到1之间的概率值，并且所有类别的概率和为1

sigmoid函数公式：
[
\sigma(x) = \frac{1}{1 + e^{-x}}
]

softmax函数公式：
[
\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_{j} e^{z_j}}
]

sigmoid的梯度：
[
\sigma’(x) = \sigma(x)(1 - \sigma(x))
]

为什么交叉熵比均方误差更适合分类问题？

当模型非常自信的预测错误，例如经过sigmoid，真实答案是1，而预测0.001，表示模型有99.9%的把握认为它不是 1
为什么MSE出现这个问题：
logits为z，经过sigmoid后为y^，真实标签为y
y^ = sigmoid(z) = 1 / (1 + exp(-z))
经过反向传播：
由于：

y^=σ(z) \hat y=\sigma(z) y^​=σ(z)

所以链式法则：

∂L∂z=∂L∂y^⋅∂y^∂z \frac{\partial L}{\partial z} = \frac{\partial L}{\partial \hat y} \cdot \frac{\partial \hat y}{\partial z} ∂z∂L​=∂y^​∂L​⋅∂z∂y^​​

MSE 第一部分：

∂L∂y^=2(y^−y) \frac{\partial L}{\partial \hat y} = 2(\hat y-y) ∂y^​∂L​=2(y^​−y)

而 sigmoid 的梯度：

∂y^∂z=y^(1−y^) \frac{\partial \hat y}{\partial z} = \hat y(1-\hat y) ∂z∂y^​​=y^​(1−y^​)

则

∂L∂z=2(y^−y)⋅y^(1−y^) \frac{\partial L}{\partial z} = 2(\hat y-y) \cdot \hat y(1-\hat y) ∂z∂L​=2(y^​−y)⋅y^​(1−y^​)

当y^接近0或1时，sigmoid的梯度会变得非常小，导致整个梯度也变得非常小，从而使得模型训练缓慢，甚至可能陷入梯度消失的问题

交叉熵的梯度会把sigmoid的梯度消掉，直接得到：

∂L∂z=y^−y \frac{\partial L}{\partial z} = \hat y - y ∂z∂L​=y^​−y
