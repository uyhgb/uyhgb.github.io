祝您成功，祝我们成功

一、1分钟英语自我介绍

建议控制在 50–60 秒、110–130词，不要把四个项目全讲一遍。

Good afternoon, professors. My name is Yiqing Wang, and I am a fourth-year undergraduate majoring in Biomedical Engineering at Beihang University.

My background combines wet-lab research with robotics and AI engineering. In robotics, I have worked on Jetson-based visual deployment and ROS integration, and I independently developed the core software pipeline of a hip exoskeleton, from IMU sensing and online SVR inference to motor actuation.

In biological research, I study bacterial spore responses under simulated microgravity, and I have also used machine learning to recommend experimental conditions and validate them in wet-lab experiments.

I am particularly interested in AI-enabled scientific instruments, edge AI, and laboratory automation. I hope to further develop these skills through this joint program. Thank you.

这版的核心信息只有三个：

Biomedical Engineering → robotics + wet lab → AI-enabled scientific instruments

非常适合戴纳。

30秒备用版

如果老师让你 “briefly introduce yourself”：

Good afternoon, professors. My name is Yiqing Wang, and I major in Biomedical Engineering at Beihang University. My experience combines wet-lab research with robotics and AI engineering. I have worked on Jetson and ROS-based robot vision, an IMU-to-motor control pipeline for a hip exoskeleton, and machine-learning-assisted biological experiments. My main interests are edge AI, intelligent scientific instruments, and laboratory automation. Thank you.

不要背得像朗诵。重点练到即使中间忘一句，也能自然跳过去。

二、你需要掌握的AI英语词汇

不要求你用英语讲完整理论，但至少做到：看到英文能认，老师说出来能听懂，需要解释时能说一两句。

中文 英文 你至少要会说什么
训练 training The model is trained on historical data.
推理 inference Inference means using a trained model to make predictions.
部署 deployment We deployed the model on an edge device.
过拟合 overfitting The model performs well on training data but poorly on unseen data.
泛化能力 generalization Generalization is the ability to perform well on unseen data.
损失函数 loss function The loss function measures the prediction error.
优化器 optimizer The optimizer updates model parameters during training.
特征 feature We extracted features from sensor data.
卷积 convolution Convolution extracts local spatial features from images.
残差连接 residual / skip connection It allows information to bypass several layers.
目标检测 object detection YOLO is commonly used for real-time object detection.
边缘计算 edge computing Computation is performed close to the device instead of in the cloud.
边缘AI edge AI AI inference runs directly on edge devices such as Jetson.
推理延迟 inference latency Lower latency is important for real-time control.
实时推理 real-time inference The model needs to run in real time.
模型量化 model quantization Quantization reduces model size and computation cost.
大语言模型 large language model / LLM An LLM is a large pretrained model mainly based on the Transformer architecture.
注意力机制 attention mechanism Attention allows the model to focus on relevant information.

智能体 AI agent An agent can plan tasks and call external tools.
工具调用 tool calling The model can call APIs or external tools.

你现在尤其应该掌握最后六个，因为专家已经明确认为你可以补“大模型”。

这句话你在戴纳面试里非常好用。

四、七套万能技术表达

你不需要为每个问题单独背答案。掌握下面几套句式即可。

1. 介绍项目目的

The goal of this project was to…

例如：

The goal of this project was to estimate the gait phase in real time and generate assistive torque accordingly.

2. 介绍系统结构

The system consists of A, B and C.

或者：

The whole pipeline is from A to B, and finally to C.

你的外骨骼可以直接说：

The whole pipeline is from IMU sensing to ROS2 communication, online SVR inference, and finally motor actuation.

3. 介绍自己负责什么

非常重要：

I was mainly responsible for…

I independently implemented…

例如：

I independently implemented the core software pipeline.

4. 介绍困难

The main challenge was…

One major issue we encountered was…

例如：

One major issue was maintaining stable communication between the computer and the motor controller.

5. 介绍解决方案

To solve this problem, I…

We addressed this issue by…

6. 说自己不知道

这个一定要会，避免卡死：

I am not very familiar with this topic yet, but my current understanding is that…

比直接说：

I don’t know.

强很多。

也可以说：

I haven’t worked on this directly, but based on my understanding…

7. 主动区分“做过”和“了解”

非常适合你：

I have hands-on experience with ROS and Jetson deployment, while my experience with large language models is mainly at the learning stage.

这句话非常诚实，而且专业。

五、AI基础最好准备这几个英文回答

1. What is ResNet?

你昨天已经被问过，最好直接固化。

ResNet, or Residual Network, introduces residual connections, also called skip connections. Instead of learning a direct mapping, a residual block learns the difference between the input and the desired output. This helps reduce the vanishing-gradient problem and makes it possible to train much deeper neural networks.

不用继续展开 ResNet-18/50，除非老师追问。

2. What is the difference between training and inference?

Training is the process of optimizing model parameters using data and a loss function. Inference means using the trained model to make predictions on new data. Training is usually computationally expensive, while inference focuses more on speed, latency and deployment efficiency.

最后一句非常适合 Jetson。

3. What is edge AI?

这个你几乎一定要会：

Edge AI means running AI models directly on local devices, such as Jetson, instead of sending all data to the cloud. Its advantages include lower latency, better privacy and higher system reliability, which are especially important for robotics and scientific instruments.

4. What is a large language model?

你现在正好需要补：

A large language model is a large pretrained neural network, usually based on the Transformer architecture. It learns language patterns from large-scale data and can perform tasks such as question answering, reasoning, information extraction and tool calling.

然后如果联系实验室：

In laboratory automation, an LLM can help understand experimental protocols, plan workflows and interact with instruments through APIs.

5. What is RAG?

RAG stands for Retrieval-Augmented Generation. Before the model generates an answer, the system retrieves relevant information from an external knowledge base and provides it as additional context. This is useful when the model needs access to private or domain-specific knowledge.

戴纳场景再补一句：

For example, the knowledge base could contain SOPs, instrument manuals and experimental records.

6. What is an AI agent?

An AI agent is a system that uses a model to understand a goal, plan actions and interact with external tools. In an autonomous laboratory, an agent could retrieve an SOP, call instrument APIs, monitor experimental results and decide the next step.

这三个：

LLM → RAG → Agent

你一定要弄清楚逻辑关系。

六、针对你自己的四个项目，至少会说这几句话

不用准备完整英文项目汇报。

RoboCup

I mainly worked on the integration and deployment of the vision pipeline. We used YOLOv5 on a Jetson Orin NX platform and integrated the vision module with ROS.

被追问是不是自己训练YOLO：

My main contribution was system integration and deployment rather than model architecture design.

这句话非常重要。

外骨骼

I independently developed the core software pipeline from IMU sensing to online gait-phase estimation and motor actuation.

I used an SVR model for continuous gait-phase estimation and converted the prediction into assistive torque commands.

模拟微重力

We used a mature simulated-microgravity device rather than developing the device ourselves.

My main work was experimental design, wet-lab experiments, microscopic counting and phenotype quantification.

这能避免昨天HR那种误解。

机器学习＋湿实验

We used machine learning to recommend candidate experimental conditions and then validated the recommended combination in a second round of wet-lab experiments.

重点一句：

So it formed a simple experiment-model-experiment closed loop.

七、很可能出现的几个英语问题

建议你直接口头练这些：

Why are you interested in this program?

My previous experience is quite interdisciplinary. I have worked with biological experiments, machine learning, robotics and edge computing. This program provides a good opportunity for me to connect these experiences and work on real intelligent scientific instruments.

What is your research interest?

My current interests are robot perception and control, edge AI, intelligent scientific instruments and laboratory automation.

Which project are you most interested in?

如果仍然选AI芯片那个：

I am currently most interested in the project on self-learning and self-optimizing equipment based on AI chips. It is closely related to my previous experience with Jetson, robot perception and model-to-device integration.

What is your weakness?

不要说英语差、AI差。

可以说：

My current experience is stronger in system integration and engineering implementation than in large language models. Therefore, I am currently learning Transformer-based models, RAG and agent systems.

这个答案现在尤其合适，因为专家已经亲自给了你这个建议。

八、面试前的实际复习方式

你不需要大量背单词。

建议每天花 60–75分钟：

20分钟：自我介绍。
连续讲5遍。目标不是背诵，而是做到任何一句忘掉都能继续讲。

20分钟：AI术语。
每天从上面随机抽10个，要求自己用英语解释一句。

例如看到：

inference

立刻说：

Inference means using a trained model to make predictions.

20分钟：随机技术问答。
随机抽：

ResNet / edge AI / RAG / agent / YOLO / ROS / your exoskeleton

要求自己英语讲30–60秒。

10分钟：项目关键词。
不用背全文，只背：

只要这几个关键词记住，即使临场紧张也可以自己组织语言。

还有一个判断：你的英语面试目标不是展现英语有多高级，而是证明“我能用英语清楚讲技术”。

因此少用复杂长句。宁愿说：

The model runs on Jetson. The output is then sent through ROS. Finally, it is converted into a motor command.

也不要为了高级感硬说一个30词的从句。

你 CET-4 574、CET-6 528，英语基础本身不是你的主要风险。真正需要训练的是把你已经会的技术知识切换成英文表达。
